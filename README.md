# موسوعة الرؤى — HTML ذاتي الاكتفاء

الملف `index.html` هو الموقع كاملاً في ملف واحد: CSS وJavaScript وقاعدة التفسيرات مضمنة داخله. ارفع هذا الملف وحده إلى استضافة تدعم HTML وJavaScript، أو استخدم `404.html` كنسخة fallback في GitHub Pages حتى تعمل روابط الصفحات الداخلية.

لا تفتح ملفات JS أو CSS منفصلة ولا تحذف أي جزء من `index.html`. يلزم اتصال بالإنترنت لتحميل خطّي Amiri وCairo وصورة الهيدر، بينما البيانات والبحث داخل الملف.

الرابط canonical مضبوط مسبقاً على https://omdapay.github.io/dreampro/. إذا نقلت الموقع إلى نطاق آخر، عدّله في رأس الملف ثم اختبر الصفحة الرئيسية، البحث، الوضع الليلي، /about، /privacy، و/contact.
